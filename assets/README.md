# 🎨 YoriForum brand assets

| File | Use | Where to upload |
|---|---|---|
| `logo.png` | Forum logo (header) | Admin → Appearance → Logo |
| `logo.png` (same file) | Favicon (browser tab icon) | Admin → Appearance → Favicon |
| `banner.jpg` | Welcome/announcement banner, social cover | Insert in welcome thread; reuse for Telegram/Discord/social headers |

Tips: keep a backup of originals; if the logo looks small in the header, it auto-scales — prefer the PNG as-is. For social avatars (GitHub org, pages), `logo.png` works as-is on dark backgrounds.
