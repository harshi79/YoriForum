# 📦 YoriForum launch content pack

Ready-to-paste content so the forum launches alive, not empty. All free to edit — make it yours.

| File | What it is | Where it goes |
|---|---|---|
| `rules.md` | Community rules | Admin → Pages → new page, slug `/rules` |
| `disclaimer.md` | Terms of Use + Disclaimer + takedown policy | Admin → Pages → new page, slug `/terms` (link it in footer + rules) |
| `faq.md` | Frequently asked questions | Admin → Pages → new page, slug `/faq` |
| `welcome-thread.md` | The big welcome + how-it-works post | Post as discussion in General → Sticky + FrontPage it |
| `ranks.md` | Rank ladder (names, points, colors) | Admin → Gamification settings (values to type in) |
| `seed-discussions.md` | 5 starter discussions | Post one per section on launch day |

After creating `/rules` and `/faq`, add them to the nav via Admin → Links (fof/links).
