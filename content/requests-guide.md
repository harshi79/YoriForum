# 📥 Requests Guide: ask right, get filled fast

*Sticky this in 📥 Requests. How the request ↔ fulfill loop works.*

## How to request
1. **Title format:** `[REQUEST] Exactly what you want` — "ebook: Atomic Habits PDF" ✅ / "plz help need" ❌
2. **One request per thread.** Search first — it may already be filled.
3. **Body template:**
   - What: (name, version, format)
   - Why/for what: (one line — helps fulfillers)
   - What you already tried:
4. Be patient and polite — fulfillers are volunteers. Don't bump before 48h.
5. **Got it?** Reply thanks + mark the best reply ✅ (= `[FULFILLED]`). Fulfillers live for this.

## For fulfillers (the heroes 🦸)
- Reply with the goods (hide big links in `[LIKE]` if you like).
- You earn: YoriCoins per reply + Helper badges + VIP consideration + eternal glory.
- **Can't fulfill it?** Don't fake it — say so or move on.
- Someone requested red-line stuff? **Don't fill it — flag it** (see below).

## ⛔ What you CANNOT request
- Red-line content (rules §3): malware, credentials/logins, personal data, paid-content dumps, phishing/fraud tools
- "Premium accounts" of any service — instant thread nuke (+ ban for repeats)
- Other people's private/paid work to repost as your own
- Homework dumps with zero effort (show your attempt → Help section instead)

Violations: thread deleted + warned first time, suspension for repeats. Fulfillers who fill banned requests share the punishment — when in doubt, flag and let mods decide.
