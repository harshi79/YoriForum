# 🔓 Unlock Guide: hidden content, likes & support

*Post this as a thread in 📤 Share Zone and sticky it. Link it from the FAQ.*

Seen grey blurred boxes in threads? That's **hidden content** — sharers hide links, passwords, and configs so only real supporters see them. It beats leechers, bots, and dead-link scrapers. Here's how the whole system works. 🤝

## Part 1 — Unlocking (for downloaders)

| Tag | How to unlock |
|---|---|
| ❤️ `[LIKE]` | Hit **Like** on the post → refresh the page → content appears |
| 💬 `[REPLY]` | **Reply** to the thread (a thanks counts!) → refresh → content appears |
| 🔑 `[LOGIN]` | Just be **logged in** (hides content from guests/bots) |

**Liked but still hidden?** ① Refresh (Ctrl+R). ② Make sure you liked *that exact post*. ③ Make sure you're logged in. Still stuck? Reply in the thread — the sharer or a mod will help.

**Golden rule:** don't copy unlocked content into public replies or other sites. Respect the hide — link the thread instead. Leakers get warned, repeaters suspended.

## Part 2 — Sharing with hidden blocks (for uploaders)

Use this template:

```
[WHAT it is + version/date + size + what's inside — be specific and honest!]

[LIKE]
link / password / config here
[/LIKE]
```

**Rules for hiders:**
- ✅ Describe honestly what's inside — fake hides ("like to see nothing") get deleted + warned.
- ✅ Archive passwords go in `[LIKE]` (the classic pattern). Big link packs: `[LIKE]` or `[REPLY]`.
- ✅ Update dead links or ask mods to close the thread. Report dead links you find.
- ❌ Don't nest tags inside tags (breaks rendering).
- ❌ Don't hide one word or junk just to farm likes.
- 🚫 Mods can see everything — hiding red-line stuff (rules §3) = instant ban.
